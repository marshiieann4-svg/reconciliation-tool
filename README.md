# Bank Reconciliation Tool

A Python tool that matches bank statements with invoices using pandas 

## What it does?
- matches payments to invoices 
- detects partial payments 
- detects duplicate payments
- flags unmatched bank transactions 
- lists unpaid invoices

## how ro run 
py reconciliation.py

## files 
-reconciliation.py - main script
-bank_statement.csv - sample bank data
-invoices.csv - sample invoice data
